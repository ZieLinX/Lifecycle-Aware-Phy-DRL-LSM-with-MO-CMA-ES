# 圆柱钨丝离线拓扑优化研究文档

## 1. 题意澄清

基于最新赛题答疑，本项目采用如下统一解释：

1. 智能体的一个决策对应一次**离线几何编辑**，随后将该新几何送入完整仿真。
2. 仿真过程中**不进行拓扑变换**；几何更新与通电求解是前后串行的。
3. `100V` 不是固定施加电压，而是**额定工况搜索中的电压上限**。
4. 对任意给定几何，需要在 `V <= 100V` 的约束下求出该几何的额定工况。
5. 热膨胀引起的几何畸变忽略，密度固定为 `19350 kg/m^3`。
6. 发射率不再随温度变化：
   - `0-3 um` 波段取 `0.35`
   - 其余波段取 `0.15`
7. 蒸发模型采用

$$
Y_e = A \exp(B / T)
$$

其中 `A = 3.9e8 [g/(cm^2*s)]`，`B = -1.023e5 [K]`。

## 2. 原始代码的主要问题

原始版本核心问题有两类：

1. 问题建模偏差
   - 将 `100V` 近似当作固定工作电压。
   - 将问题实现成常规强化学习交互，而不是“离线几何编辑 + 额定工况求解”。
2. 优化器能力不足
   - 只做一步贪心动作搜索，容易陷入局部最优。
   - 对电压搜索、热平衡求解和导出链的工程鲁棒性支持较弱。

## 3. 当前方案目标

本次改造目标不是继续堆 RL，而是构建一个更接近研究原型的**无学习离线设计优化器**：

1. 以几何参数化动作为核心。
2. 以额定工况搜索作为内层物理求解。
3. 以多步规划作为外层优化器。
4. 保留 `trimesh -> STL -> FreeCADCmd -> STEP` 导出链。

## 4. 方案结构

当前代码结构按两层组织：

1. 内层求解
   - 给定几何，搜索 `V <= 100V` 下的最佳额定工况。
   - 返回温度场、寿命、蒸发、带内辐射功率等指标。
2. 外层优化
   - 对当前几何施加一次局部形变动作。
   - 用内层求解器评估该动作后的完整状态。
   - 基于多目标评分继续选择下一步动作。

## 7. 当前代码中的“优化游戏规则”

### 7.1 一个 episode / 一步决策表示什么

当前仓库把问题实现成一个**确定性、有限时域的序列设计优化游戏**：

1. 一个 `episode` 表示从初始标准圆柱出发，经过最多 `max_steps` 次离线几何编辑，寻找更优灯丝几何。
2. `reset()` 会恢复基准圆柱，并先计算一次基准额定工况。
3. 之后每一步都不是物理时间推进，而是：
   - 先执行一次几何编辑
   - 再对新几何做一次完整额定工况重评估
   - 最后根据评估结果决定下一步

对应实现位于：

1. `train.py` 中的 `run_simulation()`
2. `envs/cylinder_env.py` 中的 `reset()` / `step()`
3. `utils/rated_condition.py` 中的 `search_rated_condition()`

### 7.2 状态

当前观测由 `_build_observation()` 构造，包含：

1. 点级三维坐标
2. 相对初始半径的径向位移
3. 归一化温度场
4. 归一化烧蚀深度
5. 一组全局指标：
   - 额定电压比例
   - 相对基准的初始带内辐射功率比例
   - 相对基准的平均带内辐射功率比例
   - 最高温度比例
   - 寿命比例
   - 视因子代理

环境内部还维护了更完整的隐状态，例如：

1. `dent_field`
2. `bulge_field`
3. `remaining_mass`
4. `current_metrics`
5. `baseline_metrics`
6. `current_step`

这些量通过 `get_state()` / `set_state()` 被规划器用于前瞻搜索。

### 7.3 动作

动作是三元组 `[index_ratio, indentation, sigma]`：

1. `index_ratio`
   - 表示在离散圆柱表面上的目标编辑位置
2. `indentation`
   - 归一化局部压陷深度
   - 实际执行时会按 `max_depth` 缩放
3. `sigma`
   - 局部编辑影响范围
   - 对应一个高斯型局部凹陷宽度

动作执行由 `_apply_design_action()` 完成，其规则是：

1. 对目标点周围施加局部 inward dent
2. 在其它可动区域施加补偿性 outward bulge
3. 通过补偿与后处理尽量维持总体积守恒
4. 电极端环若被锁定，则不参与形变

### 7.4 状态转移

一步状态转移分三段：

1. 几何编辑
   - `_apply_design_action()` 根据圆柱面近似测地距离生成局部高斯凹陷
   - 施加补偿项、最小半径约束、体积修正和电极固定约束
2. 额定工况求解
   - `_evaluate_geometry()` 先把当前几何压缩为轴向 `ring radius profile`
   - `search_rated_condition()` 在 `V <= 100V` 下搜索额定电压
   - `_evaluate_voltage()` 对每个候选电压执行一维轴向电热伪稳态迭代
3. 状态回写
   - `_update_pointwise_fields_from_metrics()` 把 ring 级温度和退蚀速率映射回点级场
   - 更新温度、烧蚀深度、剩余质量和当前指标

### 7.5 评分、回报、约束、终止

当前实现有两个层次的目标：

1. `rated_utility`
   - 用于固定几何下选额定电压
   - 综合初始带内功率、平均带内功率、温度均匀性与惩罚项
2. `score`
   - 用于 episode 内比较几何优劣
   - 综合相对基准的功率提升、寿命提升、均匀性、带内效率与惩罚项

`reward = 当前 score - 上一步 score`，表示本次几何编辑的边际收益。

主要约束包括：

1. `max_temperature <= max_temp`
2. `feature_change_ratio < feature_fail_ratio`
3. `volume_change_ratio <= volume_tolerance_ratio`
4. `lifetime_ratio >= minimum_lifetime_ratio`

终止条件为：

1. 达到 `max_steps`
2. 若启用 `terminate_on_constraints`，任一关键约束失效则终止

### 7.6 当前优化器规则

当前版本已经不是原始的一步贪心扫描，而是一个**无学习模型驱动规划器**：

1. 先根据局部 bulge、温度热点和烧蚀热点生成候选点分数
2. 再用粗粒度 `depth/sigma` 网格生成候选动作
3. 对粗候选做局部细化
4. 使用小宽度 `beam search` 做有限前瞻
5. 选择预计累计收益最大的第一步动作执行

对应实现位于 `utils/planner.py` 中的：

1. `propose_actions()`
2. `_refined_action_pool()`
3. `_search()`
4. `plan_action()`

### 7.7 近似与局限

当前“优化游戏规则”仍然是研究原型，而不是制造级高保真仿真。主要近似包括：

1. 外层优化虽然已升级为有限前瞻规划，但仍然是小宽度搜索，不是全局最优。
2. 局部几何动作是周向非轴对称的，而额定工况求解前会被压缩为 ring 平均半径，因此周向细节仍有损失。
3. 热求解采用一维轴向伪稳态迭代，而非完整 3D 多物理场求解。
4. 视因子、自遮挡和寿命都仍是代理模型。
5. STEP 导出虽然已补强为 watertight 网格 + FreeCAD 自动发现，但仍受本机 FreeCAD 实际安装位置影响。
